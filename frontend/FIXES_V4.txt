WHAT WAS WRONG:
================================================================================

ISSUE 1: O/N Column Showing "AONIA"
------------------------------------
The benchmark query was including AONIA rates:
  WHERE floating_rate IN ('AONIA','OCR','RBA','RBNZ')
                          ^^^^^^ WRONG!

AONIA is an OIS rate (Overnight Index Swap), NOT a benchmark rate.
When AONIA appeared in the O/N column, it showed the text "AONIA" 
instead of a number because the floating_rate column value was being 
displayed instead of the rate value.

FIX: Removed AONIA from benchmark query
  WHERE floating_rate IN ('RBA','RBNZ')

ISSUE 2: "no such table: benchmark_rates"
-----------------------------------------
Line 1231 was querying a table called "benchmark_rates":
  SELECT date, currency, rate FROM benchmark_rates

This table doesn't exist. All rates are in "swap_rates" table.

FIX: Changed to query swap_rates table:
  SELECT date, currency, tenor, rate FROM swap_rates
  WHERE floating_rate IN ('RBA', 'RBNZ')
