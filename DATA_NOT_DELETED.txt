WHY THIS HAPPENED:
================================================================================

The import scripts use this line:
  DATABASE_PATH = os.path.join(os.path.dirname(__file__), 'database', 'swap_rates.db')

This means: "create database in the same folder as the script"

If you put the script in RateEdge_v7.2_FINAL, it creates database there.
If your old database is in RateEdge_v7.1, you now have TWO databases.

================================================================================
TO PREVENT THIS IN THE FUTURE:
================================================================================

Always put import scripts in the SAME folder as your existing database.

Or edit the script to use an absolute path:
