ABOUT NZD DATA:
================================================================================

If you're not seeing NZD data, it's likely because:
1. NZD data hasn't been imported yet
2. The import script filtered it out
3. Database doesn't have NZD rates

TO FIX NZD DATA:
- Run your BlueGamma import script again
- Make sure NZD CSV files are in the BlueGamma folder
- Check the import logs to see if NZD data was imported

This is a DATA issue, not a GUI issue. The GUI will show NZD data as soon
as it exists in the database.
