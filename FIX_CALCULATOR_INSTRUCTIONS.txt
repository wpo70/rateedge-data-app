WHY THIS HAPPENED:
================================================================================

RateEdge expects rates in DECIMAL format:
- 3.6% interest rate = 0.036 in database

BlueGamma exports rates in PERCENTAGE format:
- 3.6% interest rate = 3.6000 in Excel file

Import scripts NOW convert percentage to decimal automatically.

But you imported data BEFORE this fix was added.

So your database has mixed format:
- Old data: decimal (0.036)
- New data: percentage (3.6)

Calculators add them: 0.036 + 3.6 = 3.636
Then display as percentage: 3.636 × 100 = 363.6

This script fixes ALL rates to decimal format.
