## 🆘 TROUBLESHOOTING

### Common Issues:

**"Module not found"**
```bash
pip install -r requirements.txt
```

**"Database not found"**
- Check you're in RateEdge_v5.1 directory
- Database is in: `./database/swap_rates.db`

**"No data shown"**
- Check date filters (data is 2018-2025)
- Try selecting "All" currencies

**Charts not displaying**
```bash
pip install --upgrade matplotlib
```

**Slow performance**
- Use date range filters
- Close unused tabs
- Export large queries to CSV
